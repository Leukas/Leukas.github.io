# Leukas.github.io

Personal site for **Lukas Edman, Ph.D.**, rebuilt in React (Vite).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` build and publish via GitHub Pages (Actions). In the repo settings, set Pages source to **GitHub Actions**.
